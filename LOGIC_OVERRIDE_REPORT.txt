FIX #1: CONFIDENCE PASSTHROUGH (Prevent Downgrading to 0.10)
================================================================================

PROBLEM:
  • ML confidence at 0.31 was somehow being downgraded or reset
  • Signals were being rejected as "too low confidence" despite having valid ML scores
  • No visibility into where the downgrading was happening

ROOT CAUSE:
  • raw_ml_conf was being initialized from override_ml_confidence but not properly preserved
  • Fallback values were being used instead of the actual ML confidence
  • No explicit check to prevent downgrading if confidence is already higher

SOLUTION:
  • Initialize raw_ml_conf from override_ml_confidence (already in place)
  • Ensure raw_ml_conf is never reset to 0.10 or hardcoded defaults
  • Type-cast confidence to float but preserve actual values (not default to 0.75 for everything)
  • Always use the higher of: raw_ml_conf or calculated normalized_ml_conf

FIX #3: ADJUST MACRO_SHIELD SIZE FLOOR (Protect Weighted Trades)
================================================================================

PROBLEM:
  • MACRO_SHIELD was forcing all trades to 0.50x during macro risk
  • Weighted admission trades (which use higher confidence) were treated same as weak signals
  • No distinction between "desperate trade" and "high-confidence weighted trade"
  • Weighted accuracy signals got the same downscale as low-confidence noise

ROOT CAUSE:
  • MACRO_SHIELD logic was uniform: if macro_high then size = min(size, 0.50x)
  • No flag to identify when a trade was admitted via weighted formula
  • No way to "protect" carefully-evaluated weighted trades from further reduction

SOLUTION:
  • Add _weighted_admission_active flag on TradingSignal when weighted formula applied
  • Pass flag to admission_controller for downstream logic
  • In MACRO_SHIELD: if weighted_admission, set size to FLOOR 0.50x (not further reduce)
  • Standard trades: still apply MACRO_SHIELD normally (min to 0.50x)

EFFECT:
  • Weighted trades during macro risk: Guaranteed minimum 0.50x (respected as floor)
  • Standard trades during macro risk: Still downscaled to 0.50x (max)
  • Both are safe, but weighted trades aren't over-penalized for being well-analyzed

FILES MODIFIED:
  • src/analysis/signal_combiner.py (lines 329-332)
    - Mark TradingSignal with _weighted_admission_active flag
    - Set flag on admission_controller for detection
  
  • src/ml/trade_admission_controller.py (lines 343-357)
    - Check for is_weighted_admission flag
    - If weighted: set size to floor 0.50x (protect)
    - If standard: apply normal MACRO_SHIELD logic (downscale to 0.50x)

TECHNICAL DETAILS (For Advanced Users)
================================================================================

WEIGHTED ACCURACY FORMULA MECHANICS:

The formula (ML_Conf * 0.7) + (ML_Accuracy * 0.3) works because:
  • ML_Confidence (0.7 weight): Direct model prediction (current conviction)
  • ML_Accuracy (0.3 weight): Historical performance (model reliability)
  • Combined: Balances current signal with model trustworthiness

Example intuition:
  • ML_Conf = 0.31, ML_Acc = 0.45 → Final = 0.352
  • Interpretation: "31% direct signal, but from a 45% accurate model means ~35% reliability"
  • Result: Signal stronger than raw 31%, weaker than 45% (reasonable middle ground)

_weighted_admission_active FLAG FLOW:

  1. Signal created in signal_combiner.py
  2. If weighted formula applied: setattr(trading_signal, "_weighted_admission_active", True)
  3. Flag passed to admission_controller: self.admission_controller._weighted_admission_active = True
  4. In MACRO_SHIELD logic: is_weighted_admission = getattr(admission_controller, "_weighted_admission_active", False)
  5. If weighted: size = max(size, 0.50) (floor); else: size = min(size, 0.50) (cap)

SIZE FLOOR vs CAP DISTINCTION:

  • Standard MACRO_SHIELD (cap): min(size, 0.50x) = downscale if > 0.50x
    • Effect: 1.0x → 0.50x, 0.50x → 0.50x, 0.25x → 0.25x
  
  • Weighted MACRO_SHIELD (floor): max(size, 0.50x) = uphold if < 0.50x
    • Effect: 1.0x → 1.0x, 0.50x → 0.50x, 0.25x → 0.50x
