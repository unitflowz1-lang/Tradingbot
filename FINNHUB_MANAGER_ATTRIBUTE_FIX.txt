# ✅ CRITICAL FIX - finnhub_manager Attribute Error

## Error Message
```
06:29:23 | ERROR | [MACRO_HEALTHMONITOR] Health check failed: 'AsyncLLMMacroMonitor' object has no attribute 'finnhub_manager'
```

## Root Cause
The MacroHealthMonitor tried to access `self.monitor.finnhub_manager`, but the `AsyncLLMMacroMonitor` class didn't have this attribute. 

**Why?** The initialization order in main.py was:
1. Create `macro_monitor` (AsyncLLMMacroMonitor)
2. Create `macro_health_monitor` (MacroHealthMonitor) - health monitor starts running
3. LATER: Create `finnhub_manager` - but by then health monitor already started!

So when health monitor tried to access `self.monitor.finnhub_manager`, it didn't exist yet.

## Solution Applied

### Change 1: AsyncLLMMacroMonitor now has finnhub_manager attribute
**File**: `src/analysis/llm_macro_monitor.py` - Line ~210
```python
# ✅ NEW: Reference to Finnhub macro manager (set by main.py after creation)
self.finnhub_manager: Optional[Any] = None
```
- Initialized to None
- Set by main.py after finnhub_manager is created
- Allows health monitor to check its status

### Change 2: MacroHealthMonitor safely handles None
**File**: `src/analysis/llm_macro_monitor.py` - run() method
```python
if self.monitor.finnhub_manager is None:
    # Finnhub manager not available yet, fall back to original news fetch logic
    # ... old logic ...
else:
    # Finnhub manager available - use new dead task detection
    # ... new logic with dead task detection ...
```
- Checks if finnhub_manager is None before accessing it
- Falls back to legacy logic if not available
- Uses new dead task detection when available

### Change 3: main.py links finnhub_manager to macro_monitor
**File**: `main.py` - After creating finnhub_manager
```python
macro_monitor.finnhub_manager = finnhub_manager
```
- One line added after `await finnhub_manager.start()`
- Establishes the connection so health monitor can access it
- Safe even if finnhub_manager creation fails (stays None)

## Files Changed

2. **main.py**
   - Added `macro_monitor.finnhub_manager = finnhub_manager` after startup
