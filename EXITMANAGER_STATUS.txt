## What You Get

### Your Problem
```
Position down -$25, held 60 hours, waiting for perfect reversal...
RSI at 32 (not quite <30)
Momentum at 0.00001 (not quite <=0)
Bot: "Need BOTH conditions... still holding"
Result: Position bleeds further 😬
```

### The Solution
```
ExitManager - 3 Safety Valves working together:

┌─────────────────────────────────────────────────┐
│  HARD LOSS THRESHOLD (-$15)  [Valve #1]         │
│  If loss > $15: CLOSE immediately               │
│  Priority: HIGHEST                              │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│  TIME-BASED STAGNATION (40 bars)  [Valve #2]   │
│  If held >40 bars: CLOSE to free capital        │
│  Priority: HIGH                                 │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│  REVERSAL EXIT (OR LOGIC)  [Valve #3]           │
│  If ANY 2 of 3 signals: CLOSE                   │
│  - RSI divergence                               │
│  - Momentum loss                                │
│  - Price action reversal                        │
│  Priority: MEDIUM                               │
└─────────────────────────────────────────────────┘
```

### Result
```
Same scenario with ExitManager:
Position down -$25, held 60 hours, RSI=32, Momentum=0.00001

Check 1: Hard Loss -$25 < -$15? YES ✓
ACTION: [HARD_LOSS_STOP] CLOSE immediately
PnL locked: -$25
Time to close: 1 cycle (~30 seconds)
Result: Position closed, capital freed ✅
```

```bash

EXIT_MANAGER_STAGNATION_BARS=40          # Stagnation limit
EXIT_MANAGER_REVERSAL_CONDITIONS=2       # Conditions required
```

**AGGRESSIVE** (protect capital quickly)
```bash

export EXIT_MANAGER_STAGNATION_BARS=20
export EXIT_MANAGER_REVERSAL_CONDITIONS=1
```

**BALANCED** (default, recommended)

## 🎯 Expected Behavior

### Hard Loss Valve
```
Trigger:  Position unrealized PnL < -$15.00
Action:   FORCE CLOSE immediately
Log:      [HARD_LOSS_STOP] EURUSD #12345 | Loss: $-21.50 | CLOSE
Wait:     <1 cycle (30 seconds)
Result:   ✅ Bleeding stopped
```

### Time-Based Valve
```
Trigger:  Position held >40 bars (40 hours at 1H bars)
Action:   CLOSE to free capital
Log:      [TIME_BASED_STOP] GBPUSD #12346 | Held: 45 bars | CLOSE
Wait:     At 40-bar mark
Result:   ✅ Capital freed for better signals
```

### Reversal Valve
```
Trigger:  Any 2 of these 3 conditions:
          - RSI<30 (LONG) or RSI>70 (SHORT)
          - Momentum<=0 (LONG) or Momentum>=0 (SHORT)
          - Bearish/bullish candles
Action:   CLOSE on reversal indication
Log:      [REVERSAL_EXIT] USDCAD #12347 | 2/3 conditions | CLOSE
Wait:     On next reversal signal
Result:   ✅ More responsive than strict AND logic
```

## 🎓 Key Improvements

### 1. Multiple Exit Triggers
**Before**: Only reversal signal (when both conditions met)
**After**: 3 independent triggers (loss, time, reversal)

### 2. OR Logic (Your Request!)
**Before**: RSI < 30 AND Momentum <= 0 (rarely both true)
**After**: RSI < 30 OR Momentum <= 0 (much more responsive)

### 3. Configurable
**Before**: Hardcoded, requires code change
**After**: Environment variables, dynamic adjustment at runtime

### 4. Safe Closure
**Before**: Manual close tracking
**After**: Same secure function as profit manager:
- `broker.close_position()` ✅
- `position_manager.shadow_positions.pop()` ✅
- `profit_mgmt.close_tracking()` ✅
