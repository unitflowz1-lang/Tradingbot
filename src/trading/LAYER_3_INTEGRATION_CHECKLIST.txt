"""
ISSUE 1: No [TIME_DECAY] messages in logs
---------
Cause: No stagnant trades being generated
Solution: 
- Reduce stop loss size to create more drawdown scenarios
- Run backtest instead of live trading
- Manually enter a losing trade to test

Cause: TIME_DECAY_ENABLED not set in environment
Solution:
- Check: export TIME_DECAY_ENABLED=True
- Verify in logs: [LAYER_3_INIT] message should appear

Cause: All positions are in profit (no drawdown window)
Solution:
- Wait for a losing position to be created naturally
- Or manually close a position at a small loss


ISSUE 2: [TIME_DECAY_FAILED] MT5 Error 4756 (Order Modify Error)
---------
Cause: New SL is too close to current price (broker minimum stop level)
Solution: Increase MIN_DISTANCE_FROM_PRICE_PIPS in TimeDecayStopLossManager
- Change: MIN_DISTANCE_FROM_PRICE_PIPS = 3.0 → 5.0
- OR: Change: SAFETY_FLOOR_PIPS = 10.0 → 15.0

Cause: SL would be placed inside the spread
Solution: This is caught by the sanity check. Check logs for:
  "New SL would exceed current price"
- Increase MIN_DISTANCE_FROM_PRICE_PIPS further


ISSUE 3: Logs show NoneType Guard messages
---------
Cause: position.stop_loss is None
Solution: Position already reached take profit or was closed
- This is normal and safe (decay is skipped)

Cause: entry_price is None
Solution: Shouldn't happen. Check Position model initialization
- Verify position_states initialization is correct


ISSUE 4: SL moving too frequently
---------
Cause: STAGNATION_BAR_THRESHOLD set too low
Solution: Increase threshold
- Change: STAGNATION_BAR_THRESHOLD = 15 → 20

Cause: STAGNATION_PRICE_THRESHOLD_PIPS too low
Solution: Increase movement threshold
- Change: STAGNATION_PRICE_THRESHOLD_PIPS = 5.0 → 10.0


ISSUE 5: SL never tightens (SHADOW MODE shows proposals but no EXECUTE messages)
---------
Cause: SHADOW_MODE = True (intended behavior)
Solution:
- Change: SHADOW_MODE = False in TimeDecayStopLossManager
- Re-run bot
- Verify [TIME_DECAY_EXECUTE] messages appear


ISSUE 6: Rapid order modifications (broker complaints)
---------
Cause: decay checking too frequently
Solution: Add cooldown
- In check_and_apply_decay(), check if last modification was < 60 seconds ago
- Skip if too recent
"""
