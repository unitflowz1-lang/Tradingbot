"""
CHECK #1: MT5 TRADE_STOPS_LEVEL VALIDATION
-------------------------------------------
Why: Brokers have minimum stop loss distances. If you violate this, MT5 rejects
     the order with Error 10016 (ERR_INVALID_STOPS).

What Layer 3 Enhanced does:
- Before moving SL, checks broker's SYMBOL_TRADE_STOPS_LEVEL
- Calculates minimum distance: (trade_stops_level * point) + spread
- Validates proposed SL meets or exceeds this distance
- Logs: [BROKER_CONSTRAINTS_CHECK] with validation result

Expected log:
  [BROKER_CONSTRAINTS_CHECK] EUR/USD | trade_stops_level=20 pts | freeze_level=0 pts | 
  min_distance=0.00200 | actual_distance=0.00150 ✗ REJECTED

If rejected: SL is too close, Layer 3 skips and waits for next opportunity


CHECK #2: BARS COUNTER FREQUENCY VERIFICATION
----------------------------------------------
Why: If manage_position() is called every 10 seconds instead of per-bar,
     bars_since_entry increments 360 times per hour instead of 1.
     This breaks the 15-bar stagnation threshold.

What Layer 3 Enhanced does:
- Tracks timestamp of each bar increment
- After 10 increments, checks if they happened within 5 minutes or 10 hours
- If within 5 min: ERROR! You're calling manage_position() per-pulse
- If within 10 hours: OK! You're calling manage_position() per-bar

Expected log (CORRECT):
  [PREFLIGHT_BARS_OK] EUR/USD: 10 bars in 36000 seconds (expected ~10 hours)

Expected log (WRONG):
  [PREFLIGHT_BARS_ERROR] EUR/USD: 10 bars in 150 seconds. 
  This indicates manage_position() is called per-pulse, not per-bar.
  Expected: 10 bars in ~36000 seconds (10 hours)

If wrong: You need to fix your main loop. manage_position() should only run
         when a new bar closes, not every data refresh.


CHECK #3: AUTO-ROTATION & HARVEST CONFLICT DETECTION
----------------------------------------------------
Why: Your bot has three systems that can modify positions:
     - Layer 3: Shrink SL on stagnant trades
     - Auto-Rotation: Close position for elite signals
     - Harvest: Close on Friday or momentum stall

     If they all run at the same time, they'll interfere with each other.

What Layer 3 Enhanced does:
- Checks if position is marked for auto-rotation
- Checks if position is already harvested
- Checks if Layer 3 already ran this cycle
- Returns early if any conflict detected
- Sets time_decay_sl_applied flag after executing

Expected log (NO CONFLICT):
  [ROTATION_CONFLICT] EUR/USD (ID:12345): No conflicts detected
  [TIME_DECAY] SHADOW MODE - EUR/USD (ID:12345) | Stagnant=15 bars ...
  (No [AUTO_ROTATION] or [HARVEST] messages for this trade)

Expected log (CONFLICT DETECTED):
  [ROTATION_CONFLICT] EUR/USD (ID:12345): Position marked for auto-rotation. 
  Skipping Layer 3 to let rotation proceed.
  (Layer 3 doesn't run, Auto-Rotation takes priority)
"""
