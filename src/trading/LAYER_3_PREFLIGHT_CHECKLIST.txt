"""
PURPOSE:
- MT5 broker enforces a minimum distance between stop loss and current price
- This is the SYMBOL_TRADE_STOPS_LEVEL property (in points)
- Layer 3 must respect this or you get MT5 Error 10016 (ERR_INVALID_STOPS)

WHAT TO VERIFY:
1. Your profit_protection_module.py already validates trade_stops_level
   (Look for: trade_stops_level checks at lines ~1671, 1679, 1682)

2. Layer 3 must also validate before proposing SL changes

3. Validation formula:
   min_distance_pips = (trade_stops_level * point) + spread

IMPLEMENTATION IN LAYER 3:
The enhanced code now includes:

    async def validate_sl_against_broker_constraints(
        self,
        position: Position,
        proposed_sl: float,
        symbol_info: Any,
        spread_pips: float,
    ) -> Tuple[bool, str]:
        '''
        Check proposed SL against broker's trade_stops_level.
        
        Returns:
            (is_valid, reason_if_invalid)
        '''
        try:
            trade_stops_level = float(getattr(symbol_info, 'trade_stops_level', 0) or 0)
            point = float(getattr(symbol_info, 'point', 0.0001) or 0.0001)
            
            # Calculate minimum distance in price units
            min_distance_from_price = (trade_stops_level * point) + (spread_pips * point)
            
            # Check proposed SL
            actual_distance = abs(proposed_sl - position.current_price)
            
            if actual_distance < min_distance_from_price:
                return False, f"SL too close ({actual_distance:.5f} < {min_distance_from_price:.5f})"
            
            return True, "OK"
        except Exception as e:
            return False, f"Validation error: {str(e)}"

VERIFICATION COMMAND (Run this in Python):
    from src.trading.LAYER_3_TIME_DECAY_ENHANCED import TimeDecayStopLossManager
    mgr = TimeDecayStopLossManager()
    
    # Simulate validation

        position=your_position,
        proposed_sl=1.0820,
        symbol_info=symbol_info,
        spread_pips=1.5
    )
    print(result)  # Should print: (True, 'OK')
"""
