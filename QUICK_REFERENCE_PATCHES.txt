PATCH #3: MACRO THREAD CRASH FIX
──────────────────────────────────────────────────────────────────────────

ERROR:
  [MACRO_HEALTHMONITOR] NEWS_FETCH restart failed.
  → Background thread dies → technical-only mode permanent

WHAT'S FIXED:
  ✅ Wraps all operations in try/except Exception (thread never dies)
  ✅ Uses threading.Event for safe restart/stop signals
  ✅ Implements exponential backoff on failures
  ✅ Graceful degradation instead of hard failure

FILE TO EDIT:
  src/analysis/llm_macro_monitor.py

CHANGES NEEDED:
  • Update MacroHealthMonitor.run() method
  • Wrap main loop in try/except Exception
  • Add _consecutive_failures tracking
  • Implement backoff: sleep 5*(1.5^failures) seconds

TIME: ~15 minutes
RISK: Medium
ROLLBACK: 5 minutes


KEY CHANGES:
────────────
OLD:
  def run(self):
      while not self._stop_event.wait(...):
          try:
              fetch_data()  # Fails
          except Exception:
              restart_thread()  # Fragile restart
          # On ANY unhandled exception: thread dies

NEW:
  def run(self):
      try:
          while not self._stop_event.is_set():
              try:
                  fetch_data()  # Fails
              except Exception as e:
                  log_error()
                  apply_backoff()
                  continue  # NEVER exit
      except Exception:
          log_critical()  # Even this is caught
      finally:
          cleanup()  # Always clean up

  • Technical-only mode: Activated permanently
  • Recovery: Requires manual bot restart

  • Recovery: Automatic within 30 minutes
