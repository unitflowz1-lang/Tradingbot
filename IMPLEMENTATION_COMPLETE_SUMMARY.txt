WHAT WAS DONE
================================================================================

Three surgical code fixes were implemented to unblock the ENSEMBLE module's
rejection loop that was preventing high-confidence ML signals from reaching
the trading admission pipeline.

ROOT CAUSE:
  The ENSEMBLE module was overriding high-confidence ML signals (e.g., 0.39
  for USD/CAD) with a default value of 0.10 during LOW_LIQUIDITY and TRENDING
  market regimes, causing them to be rejected below the NEWS_GUARD floor.

SOLUTION:
  Three targeted fixes applied to break the bottleneck:
  1. Use max(0.10, raw_ml_confidence) to pass through high signals
  2. Apply weighted accuracy formula (0.7, 0.3) before gates
  3. Replace defensive warnings with confident [WEIGHTED_ADMISSION] logging
