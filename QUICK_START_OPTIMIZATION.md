## ⚠️ TROUBLESHOOTING

### Problem: Still no trades after restart

**Solution 1**: Check what's blocking signals
```powershell
# Look for rejection reasons
Select-String -Path "logs/forex_bot.log" -Pattern "REJECTION|REJECTED" | Select-Object -Last 50
```

**Solution 2**: Lower thresholds further (if needed)
```python
# In src/analysis/signal_filter.py, line 112-116
self.min_quality_score = 0.25  # Lower from 0.30
self.min_confidence = 0.25     # Lower from 0.30
```

### Problem: Too many losing trades

**Solution**: Tighten parameters
```python
# In src/analysis/signal_filter.py
self.min_quality_score = 0.40  # Raise from 0.30
```

Or increase ML confidence requirement in main.py:
```python
# Look for ml_confidence checks
if ml_confidence < 0.56:  # Raise from 0.54
    return  # Block signal
```

### Problem: Bot won't start after changes

**Solution**: Restore backup
```powershell
# Restore original config
Copy-Item config/config.prod.json.backup.20260423_191811 config/config.prod.json

# Restart bot
python main.py
```
